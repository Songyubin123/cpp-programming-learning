# C++ 编程学习

这个仓库用于记录我的 C++ 编程学习笔记、练习代码和学习心得。

## 目录结构

- `notes/`：知识点与课程笔记
- `practice/`：练习代码与小项目
- `reflections/`：学习心得与阶段总结

## 学习内容

- C++ 基础语法
- 函数、引用与指针
- 面向对象编程
- 标准模板库（STL）
- 数据结构与算法

## 使用方式

笔记尽量使用 Markdown 编写；练习代码按主题放入独立文件夹，方便复习和运行。

## 全局文件命名规则

`notes/`、`practice/`、`reflections/` 等所有学习目录中的内容文件，统一使用“日期 + 内容”的格式命名：

```text
年_月_日_内容.扩展名
```

例如：

```text
2026_9_4_二分查找+移除元素.cpp
2026_9_4_数组学习心得.md
```

日期和内容之间、日期的年/月/日之间均使用下划线 `_`。`README.md`、`.gitignore`、`tasks.json` 等项目约定文件不受此规则限制。
