## 1. 螺旋矩阵

螺旋矩阵的核心是维护四个边界：`left`、`right`、`top`、`bottom`。

每一圈按照“上、右、下、左”的顺序填充，完成后将四个边界向内收缩。写这类题时，最重要的是统一循环区间，避免拐角被重复填写。

- 时间复杂度：`O(n²)`，矩阵中的每个元素都要填写一次。
- 额外空间复杂度：`O(1)`，不计算返回的矩阵。

## 2. 数组与内存

数组是存放在连续内存空间中的同类型数据集合，可以通过下标在 `O(1)` 时间内访问元素。

二维结构是否整体连续，要看具体类型：

- 普通二维数组 `int arr[m][n]` 整体连续。
- `vector<vector<int>>` 只保证每一行内部连续，行与行之间不保证连续。
- 如果需要连续的动态二维空间，可以使用 `vector<int> data(rows * cols)`，通过 `data[row * cols + col]` 访问元素。

## 3. `vector` 重点

`vector` 是 C++ 标准库中的顺序容器，不是普通数组，也不是由 `std::array` 实现的。它使用动态分配的连续数组保存元素，并封装了内存管理和自动扩容等功能。

### 常用初始化

```cpp
vector<int> nums;             // 空 vector
vector<int> nums1(5);         // 5 个元素，int 初始化为 0
vector<int> nums2(5, 10);     // 5 个元素，每个值都是 10
vector<int> nums3{1, 2, 3};   // 使用给定元素初始化
```

### 访问与遍历

```cpp
nums[i];       // 不检查越界，速度快
nums.at(i);    // 检查越界
nums.front();  // 第一个元素
nums.back();   // 最后一个元素
nums.data();   // 底层连续内存的首地址
```

对空 `vector` 使用下标、`front()` 或 `back()` 都是错误的，应先使用 `empty()` 判断。

只读取元素时，可以使用常量引用，避免不必要的复制：

```cpp
for (const auto& value : nums) {
    cout << value << ' ';
}
```

需要修改元素时使用普通引用：

```cpp
for (auto& value : nums) {
    value *= 2;
}
```

需要区分：

- `size()`：当前实际存在的元素数量。
- `capacity()`：当前空间最多能够容纳的元素数量。
- `reserve()`：预留容量，不创建元素。
- `resize()`：改变实际元素数量。

不能在 `reserve()` 后直接通过下标访问尚未创建的元素：

```cpp
vector<int> nums;
nums.reserve(10);
nums[0] = 1;       // 错误：此时 size 仍然是 0
nums.push_back(1); // 正确
```

常用操作的复杂度：

- 下标访问：`O(1)`。
- 末尾添加：平均 `O(1)`。
- 末尾删除：`O(1)`。
- 中间插入或删除：`O(n)`。

如果提前知道大概需要多少个元素，可以先调用 `reserve()`，减少扩容和搬移元素的次数。

`clear()` 会删除全部元素并将 `size` 变为 `0`，但通常不会立即减小 `capacity`。

函数只读取较大的 `vector` 时，应使用常量引用传参，避免复制整个容器：

```cpp
void print(const vector<int>& nums);
```

需要注意：`vector` 扩容后会更换底层内存，原来指向元素的指针、引用和迭代器可能失效。因此，不要在保存元素地址或迭代器后随意执行可能引发扩容的操作。

对于二维 `vector`：

```cpp
vector<vector<int>> matrix(rows, vector<int>(cols, 0));
```

每个内层 `vector` 代表一行。每一行内部连续，但不同行之间不保证连续；访问元素使用 `matrix[row][col]`。

## 4. 算法方法复习

### 二分查找

二分查找适用于有序数据，每次排除一半搜索范围，时间复杂度为 `O(log n)`。重点是统一区间定义、循环条件和边界更新方式。

### 双指针

双指针通过两个下标协同移动，减少重复遍历。重点是明确两个指针各自的职责，常见形式有左右指针和快慢指针。

### 滑动窗口

滑动窗口是双指针的一种应用。右指针扩大窗口，左指针在条件不满足或需要优化答案时缩小窗口。

它的关键是利用窗口状态调整起始位置，避免重复计算，从而把部分 `O(n²)` 的暴力解法优化为 `O(n)`。
