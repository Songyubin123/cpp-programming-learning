# 反转字符串 + 翻转单词学习心得

今天结合昨天（9 月 14 日）的反转字符串、分段反转字符串，以及今天（9 月 15 日）的翻转单词练习，我复盘了双指针、区间边界、字符串截取和空格处理。两天的错误主要集中在边界的含义上，这部分还需要通过手动推演巩固。

## 1. 昨天：双指针原地反转字符串

我从字符串两端开始交换字符，每次让左指针右移、右指针左移，直到两个指针相遇或交错：

```cpp
while (left < right) {
    swap(s[left], s[right]);
    left++;
    right--;
}
```

这里的 `right` 是实际参与交换的字符下标，所以初始值是 `n - 1`。奇数长度字符串中间的字符不需要交换。`vector<char>& s` 使用引用，让函数直接修改传入的数组。时间复杂度为 `O(n)`，额外空间为 `O(1)`。

## 2. 昨天：每隔 2k 个字符，反转前 k 个

分段反转时，外层循环用 `i += 2 * k` 确定每一段的起点，只反转该段前 `k` 个字符；不足 `k` 个时，把剩余字符全部反转。这里按题目要求，`k` 为正整数。

昨天聊天中的错误，是把 `reverse` 的右边界截到了 `n - 1`。但本地后来改成了手写双指针，这时用 `n - 1` 又是正确的。我需要先看清采用哪种写法：

| 写法 | 右边界的含义 | 反转到末尾时 |
| --- | --- | --- |
| `swap(s[left], s[right])` | 包含 `right`，它是最后一个字符的下标 | `right = n - 1` |
| `reverse(first, last)` | 不包含 `last`，它指向区间结束后的一个位置 | `last = s.begin() + n` |

例如 `s = "abc"`、`k = 3`，昨天聊天中的写法只反转了 `"ab"`，得到 `"bac"`；正确结果应为 `"cba"`。

```cpp
// 手写交换：包含右端点
int right = min(i + k - 1, n - 1);

// 标准库 reverse：不包含右端点
reverse(s.begin() + i, s.begin() + min(i + k, n));
```

两种写法都可以，不能混用边界。分段反转的时间复杂度为 `O(n)`；反转操作本身额外空间为 `O(1)`，当前函数按值接收 `string s`，还需要考虑字符串副本占用的 `O(n)` 空间。

## 3. 今天：翻转单词顺序

今天的题目要改变单词的排列顺序，并保留每个单词内部的字母顺序。我采用从后向前扫描的方法：跳过空格，找到单词末尾 `index`，向前找到起点 `start`，截取单词，再继续处理左边的内容。

我在聊天中重写代码时出现了两处边界错误：

- `while (index > 0)` 会漏掉下标 `0`，例如输入 `"a"` 时循环一次都不执行；应该使用 `index >= 0`。
- `while (s[start - 1] != ' ')` 缺少保护，`start` 为 `0` 时会越界；应该先判断 `start > 0`。

```cpp
while (start > 0 && s[start - 1] != ' ') {
    start--;
}
```

`&&` 先判断左边，左边不成立就不执行右边。因此边界判断要写在访问字符之前。本地今天的代码已经保留了这两处正确判断。

## 4. 今天提问的重点：substr 和 empty

`substr(起始位置, 截取长度)` 返回一段新字符串，不修改原字符串。第二个参数是字符数量，不是结束下标。

```cpp
s.substr(start, index - start + 1);
```

这里包含起点和终点，所以需要 `+ 1`。例如从下标 `4` 截取到 `6`，共有 `4、5、6` 三个字符，长度为 `6 - 4 + 1 = 3`。

`res.empty()` 表示结果是否为空，前面的 `!` 表示取反。因此下面的代码表示：已经有内容时，先加一个空格，再添加新单词。

```cpp
if (!res.empty()) {
    res += ' ';
}
res += s.substr(start, index - start + 1);
```

例如结果依次变为 `"" → "world!" → "world! hello"`。第一个单词前不加空格，后续单词前加一个空格，就能保证空格只出现在单词之间。这两个函数是今天刚弄清用途的内容，我还需要自己重新写一遍。

## 5. 本地代码的状态与后续注意点

今天本地保存的版本采用“每个单词后加空格，最后用 `substr` 去掉末尾空格”的方法，对于非空结果，这种做法成立：

```cpp
return res.substr(0, res.size() - 1);
```

如果结果为空，`res.size() - 1` 会发生无符号下溢，变成很大的数。这里 `substr(0, 很大的长度)` 会截取到末尾，空字符串仍返回空字符串，并不等于必然崩溃；但我应该先判断为空，或者使用前面“添加单词前加空格”的写法，让代码含义更清楚。

从末尾遍历时，在本题长度可以用 `int` 表示的前提下，也应先转换长度再减一：

```cpp
int index = static_cast<int>(s.size()) - 1;
```

翻转单词的方法时间复杂度为 `O(n)`，结果字符串和截取出的临时字符串需要 `O(n)` 额外空间。虽然有两层 `while`，但下标持续向前移动，每个字符只被检查有限次，并不是 `O(n²)`。

目前本地 `main()` 中，昨天只调用了 `"abcdefg", k = 2`，今天只调用了带前后空格的 `"hello world!"`。
- 翻转单词：单个字符、单个单词、连续多个空格、空字符串和全空格字符串。

两天最值得记住的方法是：写循环前，先说明每个变量代表什么，再确定区间是否包含右端点；写完后，用最短输入和恰好到边界的输入逐步检查，而不是只看普通示例。
