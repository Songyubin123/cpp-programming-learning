## 1. 二分查找

二分查找主要用于有序数据。它每次检查中间元素，并根据比较结果排除一半的数据，因此查找效率比从头到尾遍历更高。

不过，“没有重复元素”并不是二分查找必须满足的条件。数组中存在重复元素时，也可以使用二分查找，只是需要根据题目要求决定查找任意目标、最左边的目标还是最右边的目标。

编写二分查找时，要特别注意搜索区间和边界条件。例如使用闭区间 `[left, right]` 时，循环条件一般是：

```cpp
while (left <= right)
```

如果中间元素不是目标值，更新范围时需要排除已经检查过的 `mid`：

```cpp
left = mid + 1;
right = mid - 1;
```

这道题让我认识到，二分查找不能只背模板，更重要的是明确当前搜索区间代表什么，否则很容易出现遗漏元素、数组越界或者死循环。

## 2. 普通数组和 `vector`

下面两种写法创建的对象不同：

```cpp
int arr[] = {1, 2, 3};
vector<int> nums = {1, 2, 3};
```

第一种是普通数组。虽然没有手动填写数组长度，但编译器会根据初始化元素的数量，将长度推断为 `3`。数组创建以后，长度仍然是固定的，不能继续增加或缩小。

第二种是 `vector`。它是 C++ 标准库提供的动态数组，可以使用 `push_back()` 添加元素，也可以使用 `size()` 获取当前元素数量，因此使用起来比普通数组更加灵活。

需要特别注意：

```cpp
int arr[3] = {1, 2, 3};
```

表示创建一个长度为 `3` 的数组，而：

```cpp
arr[3]
```

表示访问数组中的第四个元素。对于长度为 `3` 的数组，合法下标只有 `0`、`1`、`2`，所以访问 `arr[3]` 会越界。

## 3. 值传递和引用传递

如果将 `vector` 作为函数参数，下面的写法属于值传递：

```cpp
void change(vector<int> arr)
```

调用函数时，会复制一份 `vector`。函数内部修改的是副本，因此不会改变函数外原来的数组。如果数组很大，复制还会消耗额外的时间和内存。

如果希望函数直接修改原来的 `vector`，可以使用引用传递：

```cpp
void change(vector<int>& arr)
```

这里的 `arr` 是原对象的引用，可以理解为原对象的另一个名字。修改 `arr`，就是修改调用函数时传入的那个 `vector`。由于不需要复制整个数组，也可以减少时间和内存开销。

如果函数只需要读取数组，不需要修改，可以使用常量引用：

```cpp
void print(const vector<int>& arr)
```

它既不会复制整个数组，也能防止函数意外修改原来的内容。

今天还进一步区分了 `&` 的两种含义：

```cpp
vector<int>& arr
```

这里的 `&` 出现在声明中，表示 `arr` 是引用。

```cpp
&arr
```

这里的 `&` 出现在表达式中，表示获取 `arr` 的内存地址。两者虽然都使用 `&`，但作用不同。

## 4. 快慢指针

在移除元素这道题中，快慢指针的作用是：

- 快指针负责遍历数组，寻找需要保留的元素。
- 慢指针负责记录下一个有效元素应该写入的位置。

核心代码类似于：

```cpp
int slow = 0;

for (int fast = 0; fast < nums.size(); fast++)
{
    if (nums[fast] != val)
    {
        nums[slow] = nums[fast];
        slow++;
    }
}
```

我原本把快指针理解成寻找“用于交换的元素”，但这种说法不够准确。在这道题中，元素主要是被覆盖到慢指针指定的位置，并不一定发生交换。

因此，可以把它们简单理解为：

```text
快指针负责读取和检查
慢指针负责确定写入位置
```

循环结束后，`slow` 不仅表示下一个可以写入的位置，也表示移除元素后数组中有效元素的数量。
