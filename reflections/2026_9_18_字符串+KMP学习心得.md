# 字符串与 KMP 学习心得

今天我重点复习了 KMP 的 `next` 数组，并完成了“重复的子字符串”的判断思路整理。我也把之前做过的反转字符串、分段反转、翻转单词和 `strStr` 放到同一套字符串知识中复盘。

## 今天真正弄清的内容

我现在知道 `next[i]` 表示 `s[0..i]` 的最长相同真前缀和真后缀长度。构造 `next` 时，`i` 表示当前要计算的位置，`j` 表示已经确认相同的前后缀长度。因为已经匹配的 `j` 个字符下标是 `0` 到 `j-1`，所以下一个待比较的前缀字符下标正好是 `j`，代码才会比较 `s[i]` 和 `s[j]`。

今天最难理解的是：

```cpp
j = next[j - 1];
```

现在我的理解是：当前已经确认相同的部分是 `s[0..j-1]`，它包含 `j` 个字符；如果这个长度无法继续扩大，就查询这 `j` 个字符自身的最长相同前后缀。因为最后下标是 `j-1`，所以答案存放在 `next[j-1]`。得到的新值既是还能保留的匹配长度，也是下一次要比较的前缀下标。

这行代码不是保存 `next[i]`，只是换一个更短且已经确认有效的候选。真正保存当前位置答案的是：

```cpp
next[i] = j;
```

## 今天发现的代码错误

构造 `next` 数组时，我曾让循环从 `i = 0` 开始。这样第一次会让 `s[0]` 和自己比较，使 `next[0]` 错误地变成 `1`。正确做法是让 `next[0]` 保持为 `0`，循环从 `i = 1` 开始。

判断重复子字符串时，重复单元长度不是 `next[n-1]`，而是：

```cpp
int periodLength = n - next[n - 1];
```

同时不能只判断 `n % periodLength == 0`，否则没有重复结构的 `"abc"` 也会被判断为真。正确条件是：

```cpp
next[n - 1] > 0 && n % periodLength == 0
```

我也确认了直接在 `s+s` 中查找 `s` 是错误的，因为开头一定可以找到。拼接法需要去掉第一个和最后一个字符，再查找原字符串。

## 参数和边界方面的收获

`next` 使用 `vector<int>` 时，传引用比传原始指针更清楚，因为 `vector` 自己保存长度；也可以让 `getNext` 直接返回 `vector<int>`。只读取字符串时使用 `const string&`，可以避免复制并表明函数不会修改字符串。

字符串题中反复出现的边界问题包括：数组下标从 `0` 开始、最后一个下标是 `n-1`、`substr` 的第二个参数是长度、`std::reverse` 的右边界不包含在区间内，以及访问字符前必须先检查空字符串或下标范围。

## 当前掌握程度和后续复习

我已经能解释 `next[i]`、`i`、`j` 的基本含义，也能看懂 `j = next[j-1]` 的逐步代入过程。但这个回退关系今天经过多次解释才逐渐明白，还不能算非常熟练。后续需要脱离现成代码，自己手算下面三个字符串的 `next` 数组，再独立写一次 KMP：

```text
aabaaf
aabaaa
abcabcabc
```

写完后重点检查：`i` 是否从 `1` 开始、空模式串是否处理、失败时 `i` 是否保持不动、`j` 是否按 `next[j-1]` 回退，以及重复子串公式是否使用 `n-next[n-1]`。

今天最值得保留的方法是：遇到下标公式时，先把“长度”写成具体字符区间。例如 `j=2` 就写成下标 `0、1`，这样能直接看出最后下标是 `j-1`、下一个比较位置是 `j`，不再只靠背代码。
