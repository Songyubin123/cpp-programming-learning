# 递归与二叉树前中后序遍历学习心得

今天我学习了递归的基本理解，以及二叉树的前序、中序和后序递归遍历。

## 今天掌握的重点

- 递归是函数调用自己，把大问题拆成结构相同但规模更小的子问题。
- 一个完整的递归通常包含：明确函数含义、设置终止条件、处理当前问题、递归处理更小的子问题。
- 二叉树递归遍历的终止条件是 `root == nullptr`，每次递归处理当前节点的左子树和右子树。
- 前序遍历是“根、左、右”；中序遍历是“左、根、右”；后序遍历是“左、右、根”。三者的递归结构基本相同，只是处理根节点的位置不同。
- 二叉搜索树的中序遍历结果是升序序列；后序遍历适合需要先得到子树结果，再处理父节点的场景。

## 迭代中序遍历

- 递归调用时，系统会自动使用调用栈保存函数的参数、局部信息和返回位置；迭代法则使用 `stack<TreeNode*>` 手动模拟这个过程。
- 中序迭代遍历的固定步骤是：一路向左入栈，左边到底后出栈访问，再转向右子树。

```cpp
while (cur != nullptr || !st.empty()) {
    if (cur != nullptr) {
        st.push(cur);
        cur = cur->left;
    }
    else{
        cur = st.top();
        st.pop();
        res.push_back(cur->val);
        cur = cur->right;
    }
}
```

- if负责保存沿途的左节点；出栈的节点就是当前应该访问的节点；访问后转向右子树。
- 递归是系统自动维护栈，迭代是自己维护栈；两者的核心遍历顺序相同。

## 需要注意

- 递归必须有终止条件，否则会无限调用并导致栈溢出。
- 每次递归都要让问题规模变小或更接近终止条件。
- 写二叉树遍历时，最容易出错的是忘记判断空节点，或把处理根节点的代码放错位置。
- 理解递归时不需要一次展开所有层，只要明确当前函数的作用，并相信递归调用能够正确解决更小的同类问题。
- 迭代中序遍历中，外层循环条件必须同时判断 `cur` 和栈是否为空，否则可能提前结束或访问空栈。

## 复杂度与后续复习

二叉树遍历会访问每个节点一次，时间复杂度是 `O(n)`；递归栈空间复杂度是 `O(h)`，其中 `h` 是树高。后续需要继续练习根据题目要求选择前序、中序或后序位置处理节点。
