# 今日三道题学习心得

今天我完成了三道栈相关题目，理解了栈“后进先出”的特点，以及它在匹配、消除和计算问题中的用法。

## 1. 有效的括号

我不直接把左括号入栈，而是把它对应的右括号入栈。遇到右括号时，只需要比较它是否等于栈顶，逻辑更简单。

需要注意：调用 `top()` 前必须先判断栈是否为空；遍历结束后栈也必须为空，否则说明还有未匹配的左括号。时间复杂度为 `O(n)`，空间复杂度为 `O(n)`。

## 2. 删除字符串中的所有相邻重复项

我把栈当作当前结果：如果当前字符和栈顶相同，就弹出栈顶；否则把当前字符入栈。这样可以在一次遍历中处理连续消除，以及消除后产生的新相邻重复项。

最后依次弹出栈顶时，字符顺序会反过来，所以需要 `reverse`。使用 `reverse` 时要包含：

```cpp
#include <algorithm>
```

## 3. 逆波兰表达式求值

数字入栈，遇到运算符就弹出两个数字计算，再把结果入栈。先弹出的数字是右操作数，后弹出的是左操作数，因此减法和除法必须写成：

```cpp
num2 - num1
num2 / num1
```

数字字符串需要转换为数值：`stoi` 转为 `int`，`stoll` 转为 `long long`。如果使用 `stack<long long>`，就应该配合 `stoll`，以降低整数溢出的风险。

## 共同收获

- `const string&` 是只读引用，可以避免遍历时复制字符串。
- 遇到括号匹配、相邻消除、逆波兰表达式等问题，可以优先考虑栈。
- 使用 `top()`、`pop()` 前要确认栈不为空。
- 三道题都可以在线性时间内完成，额外空间通常为 `O(n)`。
