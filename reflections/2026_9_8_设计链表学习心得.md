## 今天理解的重点

### 1. 成员变量和局部变量

成员变量定义在类里面、成员函数外面，会随着对象一直存在。局部变量只在所在函数执行期间存在。

虚拟头节点和链表长度需要被所有成员函数共同使用，所以必须定义为成员变量，不能只在构造函数中定义同名局部变量。

### 2. 虚拟头节点

虚拟头节点不属于真正的链表元素，也不计入链表长度。真正的第一个节点是：

```cpp
dummyHead_->next
```

使用虚拟头节点后，头部插入、普通位置插入和删除都可以统一为“找到目标位置的前一个节点，再修改 `next` 指针”。

### 3. 索引边界

- `get` 和 `deleteAtIndex` 的有效范围是 `0 <= index < size`。
- `addAtIndex` 允许 `index == size`，此时相当于尾部插入。
- `addAtIndex` 遇到负数索引时，需要把索引改为 `0`。
- `addAtIndex` 遇到 `index > size` 时，不插入节点。

### 4. 插入和删除的固定步骤

插入节点时：

```cpp
newNode->next = cur->next;
cur->next = newNode;
```

删除节点时，要先保存待删除节点，再断开并释放：

```cpp
ListNode* removedNode = cur->next;
cur->next = removedNode->next;
delete removedNode;
```

完成插入后要执行 `size++`，完成删除后要执行 `size--`。

### 5. 变量与标识符命名

下划线不是成员变量的语法要求，只是帮助区分变量用途的命名习惯。为了让代码容易阅读，需要选择一种风格并保持统一：

- 类名和结构体名使用大驼峰，例如 `MyLinkedList`、`ListNode`。
- 函数名使用小驼峰，例如 `addAtHead`、`deleteAtIndex`。
- 普通变量使用小驼峰，例如 `newNode`、`removedNode`、`nextNode`。
- 私有成员变量使用结尾下划线，例如 `dummyHead_`、`size_`。
- 不用大写字母开头命名普通变量，因此 `NewNode` 应改为 `newNode`，`RemovedNode` 应改为 `removedNode`。

以下形式属于 C++ 中需要避开的保留命名：

- 下划线后紧跟大写字母，例如 `_DummyNode`、`_Size`。
- 名字中出现连续两个下划线，例如 `__size`、`dummy__head`。
- 全局作用域中以下划线开头的名字。

因此，当前代码中的命名可以这样调整：

```cpp
_DummyNode  -> dummyHead_
_size       -> size_
NewNode     -> newNode
RemovedNode -> removedNode
```

成员变量和同名参数可以通过结尾下划线区分：

```cpp
void setSize(int size) {
    size_ = size;
}
```

## 复杂度

- 头部插入：时间复杂度 `O(1)`。
- 查询、尾部插入、指定位置插入和删除：最坏时间复杂度 `O(n)`。
- 保存全部节点需要 `O(n)` 空间。

## 当前需要继续修正的地方

1. `addAtIndex` 目前在判断索引是否合法之前就创建了新节点。遇到无效索引直接返回时，该节点无法释放，会造成内存泄漏。应该先检查索引，再执行 `new ListNode(val)`。
2. 链表类还没有析构函数。对象销毁时，链表中剩余的节点和虚拟头节点没有被释放，需要继续学习并补充析构函数。
3. 当前变量命名还不统一，需要将 `_DummyNode`、`NewNode` 等名字按照上面的规则调整。
