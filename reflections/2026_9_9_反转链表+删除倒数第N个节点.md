# 反转链表与删除倒数第 N 个节点学习心得

今天练习了反转链表，以及删除链表的倒数第 `n` 个节点。

反转链表时，我理解了每次改变 `cur->next` 之前，必须先保存原来的下一个节点，否则会丢失后续链表。递归写法中，`pre` 不适合定义成不会自动重置的成员变量，更安全的做法是把 `pre` 和 `cur` 作为递归参数传递。

## 反转链表的思路

我使用三个指针完成反转：

- `pre` 指向已经反转好的部分；
- `cur` 指向当前准备反转的节点；
- `temp` 临时保存 `cur` 原来的下一个节点。

每轮按照下面的顺序处理：

1. 用 `temp = cur->next` 保存后续链表；
2. 用 `cur->next = pre` 反转当前节点的指向；
3. 将 `pre` 和 `cur` 分别向后移动到 `cur` 和 `temp`；
4. 当 `cur == nullptr` 时，`pre` 就是反转后链表的新头节点。

递归写法做的事情相同，只是把下一轮的 `pre` 和 `cur` 作为参数传入下一层：

```cpp
return reverse(temp, cur);
```

删除倒数第 `n` 个节点时，我先使用了统计长度的方法。待删除节点的前驱位置应按 `size - n - 1` 计算，同时要特别处理删除头节点的情况。

之后我学习了更常用的快慢指针方法：让 `fast` 先走 `n` 步，再让 `fast` 和 `slow` 同时移动。当 `fast` 到达最后一个节点时，`slow->next` 就是待删除节点。加入虚拟头节点后，删除头节点和删除普通节点可以使用同一套逻辑。

## 删除倒数第 N 个节点的思路

### 方法一：先统计长度

1. 遍历一次链表得到长度 `size`；
2. 倒数第 `n` 个节点是正数第 `size - n + 1` 个节点；
3. 删除节点前要先找到它的前驱节点，因此从头节点移动 `size - n - 1` 次；
4. 使用 `cur->next = cur->next->next` 跳过目标节点，再释放目标节点。

这个方法要单独处理删除头节点的情况，因为头节点没有前驱节点。

### 方法二：快慢指针

1. 创建虚拟头节点，让它指向原链表头节点；
2. `fast` 和 `slow` 都从虚拟头节点出发；
3. 让 `fast` 先移动 `n` 步，使两个指针之间保持固定距离；
4. 两个指针同时移动，直到 `fast` 到达最后一个节点；
5. 此时 `slow` 正好位于待删除节点的前一个节点，删除 `slow->next` 即可。

虚拟头节点让原头节点也拥有前驱节点，因此不需要再单独处理删除头节点的情况。

需要注意：

- 修改链表指针前，先保存后续节点。
- `while (front--)` 遇到负数仍会继续执行，使用 `while (front > 0)` 更清楚、安全。
- 使用 `new` 创建的节点要考虑 `delete`；虚拟头节点可以直接创建在栈上，避免内存泄漏。
- 删除节点后，把即将离开作用域的局部指针设为 `nullptr` 通常没有必要。

两道题的时间复杂度都是 `O(n)`。迭代反转链表和快慢指针删除节点的额外空间复杂度都是 `O(1)`；递归反转链表会使用 `O(n)` 的调用栈空间。
