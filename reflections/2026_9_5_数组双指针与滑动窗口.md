# 今日 C++ 学习心得

今天练习了两道数组题：长度最小的子数组和有序数组的平方。两道题都可以先用容易理解的方法解决，再根据数组本身的特点进行优化。通过这两道题，我进一步熟悉了 `vector`、循环边界、双指针以及时间复杂度分析。

## 1. 长度最小的子数组

题目要求在正整数数组中，找到元素和大于等于 `target` 的最短连续子数组。

### 当前思路：两层循环

当前代码枚举每一个起点 `i`，再从这个起点向右累加：

```cpp
for (int i = 0; i <= size - 1; i++) {
    int val = 0;
    for (int j = i; j <= size - 1; j++) {
        val += nums[j];
        if (val >= target) {
            res = min(res, j - i + 1);
            break;
        }
    }
}
```

当总和第一次达到 `target` 时立即 `break` 是正确的。因为数组中的元素都是正整数，继续向右扩大子数组只会让长度更长，不可能得到以当前 `i` 为起点的更短答案。

这种写法清楚地表达了“固定起点，寻找最短终点”的过程，示例 `[2,3,1,2,4,3]`、`target = 7` 可以得到正确答案 `2`。


### 复杂度和优化方向

当前解法最坏情况下需要两层循环：

- 时间复杂度：`O(n²)`
- 空间复杂度：`O(1)`

由于数组元素都是正数，可以进一步使用滑动窗口。右指针负责扩大窗口并增加总和；当窗口总和达到 `target` 时，左指针向右移动，尝试缩小窗口并更新最短长度。

核心规律是：

```text
总和不足时，移动右指针扩大窗口
总和达标时，移动左指针缩小窗口
```

左右指针都只会向前移动，每个元素最多进入和离开窗口一次，因此可以把时间复杂度优化到 `O(n)`。

## 2. 有序数组的平方

题目给出一个非递减排列的整数数组，要求返回各元素平方后仍按非递减顺序排列的新数组。

### 基础思路：平方后排序

最直接的方法是先将每个元素平方，再调用 `sort()`：

```cpp
for (int i = 0; i < nums.size(); i++) {
    nums[i] *= nums[i];
}
sort(nums.begin(), nums.end());
```

这种方法容易理解，时间复杂度为 `O(n log n)`。当前代码将它保留为注释，然后进一步写出了效率更高的双指针解法，这体现了从“先完成”到“再优化”的解题过程。

### 优化思路：相向双指针

负数平方后可能变大，所以不能直接从左向右平方。但是原数组已经有序，绝对值最大的元素一定在当前区间的左端或右端。

代码用 `left` 和 `right` 指向两端，比较两端元素的绝对值，把较大者的平方放到结果数组末尾：

```cpp
int left = 0;
int right = nums.size() - 1;
int k = right;

while (left <= right) {
    if (abs(nums[left]) > abs(nums[right])) {
        res[k--] = nums[left] * nums[left];
        left++;
    } else {
        res[k--] = nums[right] * nums[right];
        right--;
    }
}
```

这里最关键的对应关系是：

```text
左右两端负责提供当前最大的平方值
k 负责记录这个值在结果数组中的最终位置
```

当前实现的时间复杂度是 `O(n)`，额外空间复杂度是 `O(n)`。示例 `[-4,-1,0,3,10]` 的运行结果为 `0 1 9 16 100`，结果正确。

## 3. 两道题中的双指针区别

虽然两道题都会用到两个指针，但移动方式和目的不同。

| 题目 | 指针形式 | 移动规则 | 目的 |
| --- | --- | --- | --- |
| 长度最小的子数组 | 同向双指针 | 右指针扩大窗口，左指针缩小窗口 | 找到满足条件的最短区间 |
| 有序数组的平方 | 相向双指针 | 比较两端后移动其中一个指针 | 按从大到小的顺序确定平方值 |

因此，双指针不是一套固定代码，而是一种减少重复遍历的思想。需要根据题目的条件判断指针从哪里开始、何时移动，以及每个指针承担什么职责。

## 4. 可以继续改进的代码习惯

如果函数只读取数组，可以在题目签名允许时使用常量引用：

```cpp
vector<int> sortedSquares(const vector<int>& nums)
```

输出 `vector` 时也可以使用范围 `for` 循环：

```cpp
for (int value : res) {
    cout << value << " ";
}
```

编写循环条件时，`i < size` 通常比 `i <= size - 1` 更直观，也更容易处理空数组：

```cpp
for (int i = 0; i < size; i++)
```

## 今日总结

今天最大的收获是开始根据题目的数据特征选择算法。长度最小的子数组利用了“所有元素都是正数”，因此窗口扩大时总和只会增加，窗口缩小时总和只会减少；有序数组的平方利用了“原数组有序”，因此最大的平方值只能来自两端。

以后遇到数组问题，可以先问自己三个问题：

1. 数组是否有序？
2. 元素是否全部为正数，某个量是否会单调变化？
3. 是否可以通过移动指针，避免重复检查已经处理过的区间？
