## 核心理解

### 1. STL 与容器适配器

STL（Standard Template Library）是 C++ 标准库中提供的通用容器、算法和迭代器等工具。

`vector`、`deque`、`list` 是底层序列容器；`stack`、`queue` 是容器适配器。适配器会复用底层容器的存储能力，但只向外提供符合栈或队列规则的接口。

例如，`stack` 默认可以使用 `deque` 作为底层容器，但它只提供 `push`、`pop`、`top` 等栈操作，不提供下标访问和迭代器。

### 2. `deque` 不是链表

`deque` 是双端队列，支持从头尾两端插入和删除，并且支持随机访问。它通常由多个内存块组成，整体不一定连续。

链表则由节点和指针连接起来。`std::list` 通常是双向链表，不能通过下标随机访问，但在已知节点位置时插入和删除很方便。

因此：

- `deque`：分段数组，支持随机访问，两端操作高效；
- `list`：节点加指针，不支持随机访问，节点位置确定时插入和删除高效。

### 3. `this->pop()`

在成员函数中，`this` 是指向当前对象的指针。

```cpp
this->pop();
```

表示调用当前对象的 `pop()`，等价于：

```cpp
pop();
(*this).pop();
```

## 代码分析

### 两个栈实现队列

```cpp
std::stack<int> stIn;
std::stack<int> stOut;
```

我需要维护两个规则：

- `stIn` 只负责接收新元素；
- `stOut` 只负责取出队头元素；
- 只有当 `stOut` 为空时，才把 `stIn` 的元素全部转移过去。

转移会把元素顺序反转，使最早进入的元素位于 `stOut.top()`。每个元素最多转移一次，因此 `push` 是 `O(1)`，`pop` 和 `peek` 的均摊复杂度是 `O(1)`。

`peek` 可以在 `stOut` 不为空时直接返回 `stOut.top()`，不需要先 `pop` 再放回，这样逻辑更直接。

### 两个队列实现栈

将 `q1` 中除最后一个元素以外的元素转移到 `q2`，留下的最后一个元素就是栈顶。弹出后再交换两个队列：

```cpp
std::swap(q1, q2);
```

这种实现是正确的，但每次 `pop` 或 `top` 可能要移动很多元素，复杂度为 `O(n)`；`push` 和 `empty` 通常为 `O(1)`。
